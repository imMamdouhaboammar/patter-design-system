Core Architecture

What the design system provides.

A complete, cohesive suite of tokens and primitives crafted for high-density applications.

01 / Palette

Ink & Peach Palette.

Deterministic high contrast with deep ink `#000000` surfaces and signature `#df9367` peach highlights.

--peach: #df9367; --ink: #000000;
02 / Typography

Dual-Typeface Hierarchy.

Instrument Sans for human-readable headlines and JetBrains Mono for telemetry, data, and code.

Instrument Sans · JetBrains Mono
03 / Shadows

Tactile Hard Shadows.

Multi-tier hard black drop shadows that provide architectural depth without blurry blur effects.

12px 12px 0 0 #000000
04 / Multi-Format

CSS + Tailwind + W3C.

Available as standard CSS Custom Properties, a plug-and-play `tailwind.config.js`, and W3C DTCG JSON.

tokens.json · tailwind.config.js · index.css
05 / Micro-Textures

Dot-Grid Backgrounds.

18px radial micro dot grids providing fine texture across technical dashboard cards and hero frames.

radial-gradient(1px 1px, #dad8de)
